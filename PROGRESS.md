- **How to run it:** open Control Center from Applications. After merging into `main`, run `bun run app` in the main checkout so the installed app gets the change. `bun run desktop` opens a development copy. For a browser check on its own port: `bun run build`, then `PORT=<free port> CC_APP_DIR=<empty folder> bun server/src/index.ts` and open http://127.0.0.1:<port>.
- **How to test it:** `bun run typecheck && bun run test && bun run build`. The session-ID endpoints, the model switch and the send-after-stop wait are tested with a stand-in for the Agent SDK in `server/test/api.test.ts` ("a conversation is addressed by its session ID"); the mid-turn message and the dropped "No response requested." line in `server/test/parsers.test.ts`; the New session page's address, project choice, first page of data, and that every New session button opens `/sessions/new` in `server/test/newSession.test.ts`. The pages themselves have no automated test; check them in a browser.
