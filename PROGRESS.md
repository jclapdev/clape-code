- **Last step done:** 002-S5, the main menu, verified passing (A9, A10) in a browser with real Claude sessions in claude-test: "Continue last conversation" opened the conversation last sent a message in from Home, Settings, Skills and Customize; a session waiting for approval of a file write showed under "Needs you" and left it after Deny; a session running a shell command showed under "Working". Start, reply, leave and come back via the menu at 390, 768, 1024 and 1440 px in light and dark: no page or pane scrolled sideways and the reply box stayed at the bottom of the window. What it does: under Sessions, the menu has "Continue last conversation", which opens the conversation you last sent a message in; then "Needs you" and "Working" headings, each listing up to 5 conversations by title with a coloured dot, and "N more" linking to Sessions (with "Needs you" on for the first). On tablets (768 to 1279 px) the icon strip has "Continue" and a three-line title per conversation; on phones the full-screen menu has the full version. The data comes from a new `GET /api/menu` (`server/src/api/sessions.ts`), which sends only session ID, job ID, title and project for `last`, `needsYou` and `running`, leaving out runs from scripts and archived conversations, as Sessions does. "Last sent a message in" uses a new `lastPromptAt` on each indexed session (the last typed prompt or message sent while Claude worked; `server/src/parsers/transcript.ts`; index schema bumped to 7), not the last activity, so a session where only Claude wrote later doesn't win. The "Needs you" and "Working" lists use the same live requests, blocked background sessions and `sessionActivity` as Home and Sessions. The menu query refreshes on session, job and live changes. Checked once in a browser on its own port with a real one-line session in claude-test: from Home, Settings and Skills, "Continue last conversation" opened that session (full menu at 1440, rail at 1024); a script over Home, Sessions, a conversation, New session, Settings and Skills at 390, 768, 1024 and 1440 px in light and dark found no page or pane scrolling sideways and the reply box inside the window every time.
